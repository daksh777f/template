# Dishu UI Template

A modern React template with Tailwind CSS, Framer Motion, and React Scroll Parallax for creating stunning, interactive web experiences.

## Features

- ⚡ **Fast Development** - Powered by Vite for lightning-fast builds
- 🎨 **Beautiful Styling** - Tailwind CSS for modern, responsive design
- 🚀 **Smooth Animations** - Framer Motion for fluid interactions
- 📱 **Parallax Effects** - React Scroll Parallax for engaging scroll experiences
- 🔧 **Easy to Customize** - Clean component structure for rapid development

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── layouts/        # Layout components
├── pages/          # Page components
├── App.jsx         # Main application component
├── main.jsx        # Application entry point
└── index.css       # Global styles and Tailwind imports
```

## Built With

- [React](https://reactjs.org/) - UI library
- [Vite](https://vitejs.dev/) - Build tool
- [Tailwind CSS](https://tailwindcss.com/) - CSS framework
- [Framer Motion](https://www.framer.com/motion/) - Animation library
- [React Scroll Parallax](https://react-scroll-parallax.damnthat.tv/) - Parallax effects
