# React + Tailwind landing-page template

A reusable starter for animated landing pages, built with React 19, Vite, Tailwind CSS 4, Framer Motion and React Scroll Parallax.

## Contents

| Path | What it is |
|---|---|
| `template/` | The template app: `MainLayout`, `Navbar`, `Footer`, `Section`, `Card` and a `ParallaxHero` component, plus a shared theme |
| `start/` | Early experiments with the parallax hero and theme |

## Run

```bash
cd template
npm install
npm run dev      # start the Vite dev server
npm run build    # production build
```

See [`template/README.md`](template/README.md) for customisation notes.
